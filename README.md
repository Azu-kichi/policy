GitHub Pages で公開するためのリポジトリ。**アプリ本体のコードは含まない。**

- 正本は [index.md](index.md)。**文面はアプリの実装と一致していなければならない** —

  制定日・更新日を書き換えること
- 文面の根拠（一次情報・確認日つき）はアプリ側リポジトリの `docs/PLAY_LAUNCH.md` §4
